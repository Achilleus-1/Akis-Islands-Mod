**Alpha for Minecraft 1.21.1, NeoForge 21.1.265+, and Java 21.**

Create one continent, attached continents, or an island group surrounded by ocean, with a coastline preview before world creation.

### Features

- Native **World Type: Aki's Islands → Customize** editor with radius, landmass count, and Randomize Shape.
- Optional cold-north / broad-temperate-middle / hot-south climate. The middle defaults to 65%; middle width, band strength, and transition length are adjustable.
- Per-world settings, retained vanilla/modded biome selection, and native humidity, terrain, caves, ores, and structure stages.
- Automatic climate delegation when Natural Temperature is installed.
- Supplied Aki's Islands cover artwork and matching packaged icons.

### Installation

Download the installable `akis-islands-mod-1.21.1-0.3.0-alpha.jar`, place it in `mods`, and remove older Aki's Islands jars. Install the same version on the server and participating clients for multiplayer. Select **World → World Type: Aki's Islands → Customize** when creating a new world. Latitude climate starts off.

Keep the dependencies required by your other mods installed. To use Aki's latitude controls, omit Natural Temperature; otherwise its own climate settings remain in control.

### Alpha scope

Compatibility is not universal. Individual Integrated Village placement, long stream/railway routes, and the new climate editor's visual click-through still need gameplay verification. See the [compatibility report](https://github.com/Achilleus-1/Akis-Islands-Mod/blob/v0.3.0-alpha/docs/COMPATIBILITY.md) before using this alpha in a long-term world. Existing saves retain their stored settings; installing the mod does not convert an ordinary world.
