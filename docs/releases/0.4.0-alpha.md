**Alpha for Minecraft 1.21.1, NeoForge 21.1.265+ in the 21.1 series, and Java 21.**

### Changes

- **Mixed continents** adds 2–6 large landmasses with randomized satellite islands, occasional land bridges, coves, and peninsulas. Select it in **World Type: Aki's Islands → Customize** and use **Randomize Shape** for another arrangement.
- Climate presets: **Default**, **Balanced** (roughly 50% moderate / 25% cold / 25% hot), **Temperate**, and **Gentle**. Values remain adjustable. Percentages describe planned latitude spans, not exact biome areas.
- **Reset to default** restores 65% middle, 85% strength, and 100% transition length without changing climate on/off.
- New climate settings use smoother easing at the band joins. Existing saves keep their previous curve unless climate values are edited; the original three layouts keep their coastlines.

### Installation

Install `akis-islands-mod-1.21.1-0.4.0-alpha.jar` in your NeoForge `mods` folder and remove the previous Aki's Islands jar. Use the same version on servers and participating clients. Keep your other mods' dependencies installed.

Latitude climate remains optional and starts off. When Natural Temperature is installed, it continues to own climate and Aki's controls defer automatically.

### Alpha scope

Compatibility is not universal. Individual structure placement, long stream/railway routes, and visual click-through of the climate editor still need gameplay verification. See [compatibility and limitations](https://github.com/Achilleus-1/Akis-Islands-Mod/blob/v0.4.0-alpha/docs/COMPATIBILITY.md). Existing ordinary saves are not converted into continent worlds.
