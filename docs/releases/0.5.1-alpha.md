**Alpha for Minecraft 1.21.1, NeoForge 21.1.265+ in the 21.1 series, and Java 21.**

### World generation compatibility

- Fixed Hybrid Aquatic 1.7.4 skipping ocean trenches with Aki's continent generator.
- Added serializable terrain and climate density functions so generation integrations can inspect the active terrain.
- Spawn's independent cold, Dodo, sandy, tropical, and volcanic island structures now respect the planned land area, preventing extra islands in the endless ocean. They may have fewer eligible locations. Other structures retain their normal placement rules.
- Reviewed the updated WIP generation stack, including Streams Reflowing 2.17.3 and its newer terrain, shore, and dimension settings. See the [compatibility audit](https://github.com/Achilleus-1/Akis-Islands-Mod/blob/v0.5.1-alpha/docs/WIP-WORLDGEN-AUDIT.md) for supported test scope and upstream issues.

### Installation

Replace the older Aki's Islands jar with `akis-islands-mod-1.21.1-0.5.1-alpha.jar` in your NeoForge `mods` folder. Use the same version on servers and participating clients. The changes apply to newly generated chunks; previously saved islands remain in their chunks.
