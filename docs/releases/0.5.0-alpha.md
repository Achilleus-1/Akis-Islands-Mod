**Alpha for Minecraft 1.21.1, NeoForge 21.1.265+ in the 21.1 series, and Java 21.**

### Larger cold and hot bands

- **Normal middle** now adjusts from **10–90%**, so the temperate center can be much narrower.
- New **Wide extremes** preset: **25% middle, 90% band strength, 75% transition length**. The narrower middle and shorter transition reach strong cold/hot temperatures sooner, leaving more room for the frozen north and hot south.
- Updated tooltips explain how to customize those proportions. Transitions remain smooth, and the default stays 65% / 85% / 100%.

Open **World Type: Aki's Islands → Customize → Climate**, enable north-to-south climate, and cycle **Preset** to **Wide extremes**. Choose **Done**, then **Apply layout**. You can adjust the sliders afterward or use **Reset to default**.

Percentages describe planned latitude spans, not guaranteed biome areas. Humidity and the pack's biome rules still control which hot/cold biomes appear. When Natural Temperature is installed, it continues to own climate.

### Installation

Replace the older Aki's Islands jar with `akis-islands-mod-1.21.1-0.5.0-alpha.jar` in your NeoForge `mods` folder. Use the same version on servers and participating clients. Climate middle values below 50% require this version or newer. Existing worlds retain their stored climate values; installing the update does not apply the new preset to them.

See [compatibility and limitations](https://github.com/Achilleus-1/Akis-Islands-Mod/blob/v0.5.0-alpha/docs/COMPATIBILITY.md).
