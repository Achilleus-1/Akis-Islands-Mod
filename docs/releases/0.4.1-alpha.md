**Alpha for Minecraft 1.21.1, NeoForge 21.1.265+ in the 21.1 series, and Java 21.**

### Ocean boundary correction

The coastline plan now enforces an ocean boundary after terrain density evaluation. Terrain branches that add land independently of the large-scale land/ocean signal are suppressed outside the planned coast, addressing unexpected islands beyond the preview.

The safeguard preserves inland terrain, existing air/water/cave density, and submerged density more than 16 blocks below sea level. Mixed continents, randomized satellite islands, climate settings, and the normal structure/feature stages remain available.

### Installation and existing worlds

Replace the previous Aki's Islands jar with `akis-islands-mod-1.21.1-0.4.1-alpha.jar` in your NeoForge `mods` folder. Use the same version on servers and participating clients, and keep other mods' dependencies installed.

The correction applies to newly generated chunks. Unexpected islands already generated by an older version remain stored in the save; this update does not erase chunks. A new test world shows the corrected boundary throughout the layout. Original format-1 worlds retain their legacy generation.

Structures and features added after terrain noise retain their own rules, including any blocks they place above water. See [compatibility and limitations](https://github.com/Achilleus-1/Akis-Islands-Mod/blob/v0.4.1-alpha/docs/COMPATIBILITY.md).
