# Security

Security fixes target the current `main` branch. This is alpha software.

Report suspected vulnerabilities through [GitHub private vulnerability reporting](https://github.com/Achilleus-1/Akis-Islands-Mod/security/advisories/new) if available. Otherwise contact the maintainer through the [Achilleus profile](https://github.com/Achilleus-1) before disclosing sensitive details.

Include the affected version, impact, and a minimal reproduction. Do not put credentials, private server addresses, personal paths, or unredacted logs into public issues. Share a minimal reproducible seed and configuration instead of an entire private world save.

The runtime mod performs world generation and local configuration; it does not download compatibility mods. The optional development downloader is a separate script that runs only when explicitly invoked.
